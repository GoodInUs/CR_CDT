Cognitive Urban Twin — Protégé Starter Package

Open:
  cognitive-urban-twin-v0.1.ttl

In Protégé:
  File → Open… → select the TTL file.

Optional validation companion:
  cognitive-urban-twin-shapes-v0.1.ttl

Modelling choices:
- UML classes → OWL classes
- inheritance → rdfs:subClassOf
- associations → OWL object properties
- attributes → datatype properties
- UML operations → annotations only
- selected multiplicities → OWL restrictions
- closed-world validation → SHACL
