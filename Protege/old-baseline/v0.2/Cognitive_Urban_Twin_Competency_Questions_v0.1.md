# Cognitive Urban Twin — Competency Questions v0.1

These competency questions are intended to test whether the ontology can represent and support the core reasoning needed by the Cognitive Urban Twin.

## CQ1 — Hazard exposure
**Question:** Which data centres are threatened by a given weather hazard?

**Primary classes:** `WeatherHazard`, `DataCentre`  
**Primary property:** `threatens`  
**Expected answer pattern:** one hazard → zero or more data centres

---

## CQ2 — Service dependency
**Question:** Which urban services depend on a given data centre?

**Primary classes:** `UrbanService`, `DataCentre`  
**Primary property:** `dependsOn` / inverse `isDependedOnBy`

---

## CQ3 — Power dependency
**Question:** Which data centres are supplied by a given electricity grid?

**Primary classes:** `ElectricityGrid`, `DataCentre`  
**Primary property:** `suppliesElectricityTo`

---

## CQ4 — Grid constraints
**Question:** Which grid constraints are currently relevant to a data centre?

**Primary classes:** `DataCentre`, `GridConstraint`, `ElectricityGrid`  
**Primary properties:** `contributesDemandTo`, `experiencesGridConstraint`

---

## CQ5 — Impact assessment
**Question:** Which impact forecasts are associated with a given weather hazard?

**Primary classes:** `WeatherHazard`, `ImpactForecast`  
**Primary property:** `hasHazardInput`

---

## CQ6 — Vulnerability and exposure
**Question:** Which vulnerability and exposure profiles inform a given impact forecast?

**Primary classes:** `VulnerabilityProfile`, `ExposureProfile`, `ImpactForecast`  
**Required relationship:** `informedBy` or equivalent explicit sub-properties

---

## CQ7 — Service risk
**Question:** Which urban services are potential impact targets of an impact forecast?

**Primary classes:** `UrbanService`, `ImpactForecast`  
**Primary property:** `hasServiceImpactTarget`

---

## CQ8 — Flexibility availability
**Question:** Which flexible resources can respond to an identified grid or data-centre constraint?

**Primary classes:** `FlexibleResource`, `BatteryStorage`, `ComputeFlexibility`, `ElectricVehicleFleet`  
**Primary properties:** `providesComputeFlexibility`, dependency hierarchy

---

## CQ9 — Elastic workload flexibility
**Question:** Which elastic data loads can be deferred or throttled to release compute capacity?

**Primary classes:** `ElasticDataLoad`, `ComputeFlexibility`, `WorkloadManagement`  
**Primary property:** `providesComputeFlexibility`

---

## CQ10 — Cognitive-twin state
**Question:** What observation base, knowledge base and decision base belong to a particular Cognitive Twin?

**Primary class:** `CognitiveTwin`  
**Primary properties:** `hasObservationBase`, `hasKnowledgeBase`, `hasDecisionBase`

---

## CQ11 — Scenario generation
**Question:** Which prediction/scenario engine receives the current state and semantic model used by the Cognitive Twin?

**Primary classes:** `ObservationBase`, `KnowledgeBase`, `PredictionScenarioEngine`  
**Primary properties:** `providesStateTo`, `providesModelTo`

---

## CQ12 — Recommendation generation
**Question:** Which decision recommendations were generated by a Cognitive Twin?

**Primary classes:** `CognitiveTwin`, `DecisionRecommendation`  
**Primary property:** `generatesRecommendation`

---

## CQ13 — Recommendation assurance
**Question:** What explanation and assurance record justifies a given decision recommendation?

**Primary classes:** `DecisionRecommendation`, `ExplanationAssurance`  
**Primary property:** `justifiedBy`

---

## CQ14 — Recommended actions
**Question:** Which anticipatory actions are recommended by a decision recommendation?

**Primary classes:** `DecisionRecommendation`, `AnticipatoryAction`  
**Primary property:** `recommendsAction`

---

## CQ15 — Action feedback
**Question:** Which action outcomes have been returned to the observation base for future reasoning?

**Primary classes:** `AnticipatoryAction`, `ObservationBase`  
**Primary property:** `returnsOutcomeDataTo`

---

## CQ16 — Data-centre response actions
**Question:** Which data-centre feedback actions can act on a threatened or constrained data centre?

**Primary classes:** `DataCentreFeedbackAction`, `WorkloadManagement`, `GridBrokering`, `CoolingWaterManagement`, `RecoveryPlanning`, `DistrictHeatingControl`

---

## CQ17 — Urban-service response actions
**Question:** Which urban-service feedback actions can protect or adapt an affected urban service?

**Primary classes:** `UrbanServiceFeedbackAction`, `CivicEmergencyResponse`, `SocioEconomicResponse`, `ServiceModeControl`

---

## CQ18 — Semantic representation
**Question:** Which domain entities are represented or interpreted by the Cognitive Twin Knowledge Base?

**Primary class:** `KnowledgeBase`  
**Primary properties:** `represents`, `interprets`

---

## CQ19 — Traceability
**Question:** Can a recommendation be traced from hazard and observed state through impact forecast, analytic reasoning, decision recommendation and action?

**Required chain:**  
`WeatherHazard` → `ImpactForecast` → `PredictionScenarioEngine` → `CognitiveTwin` → `DecisionRecommendation` → `AnticipatoryAction` → `ObservationBase`

---

## CQ20 — Decision readiness
**Question:** Is a decision recommendation sufficiently complete to be considered actionable?

**Minimum validation requirements:**  
- exactly one recommendation identifier  
- at least one recommended action  
- exactly one explanation/assurance record  
- confidence value present  
- decision deadline present when time-critical

This competency question is intended to be enforced using SHACL.
